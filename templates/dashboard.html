About the System

This system uses Natural Language Processing and machine-learning-based similarity techniques to analyze candidate resumes.

The system identifies relevant skills, calculates resume similarity, calculates skill matching, and stores screening results in MySQL.

Main Features

  • Multiple resume upload
  • Resume text extraction
  • NLP-based processing
  • Skill matching
  • Resume similarity calculation
  • Candidate ranking
  • MySQL database storage
  • Candidate details and AI screening explanation
  • Screening history
  • Dashboard and report generation
